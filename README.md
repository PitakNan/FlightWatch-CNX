# FlightWatch CNX

ติดตามราคาตั๋วเครื่องบินจากเชียงใหม่ไป 6 ปลายทาง (ดอนเมือง สุวรรณภูมิ ภูเก็ต หาดใหญ่ สมุย กระบี่)
สำหรับ 3 ที่นั่ง — ผู้ใหญ่ 2 + เด็ก 11 ปี 1 (เด็ก 11 ปีจ่ายเท่าผู้ใหญ่บนสายการบินโลว์คอสต์)

- ราคาจริงจาก Google Flights สแกนอัตโนมัติวันละ 5 รอบ
- เรดาร์โปรโมชั่นจากหน้าสายการบิน + ข่าว
- สรุปเข้า LINE ทุกรอบ

หน้าแนวโน้ม: https://pitaknan.github.io/FlightWatch-CNX/

ตัวสคริปต์อยู่เครื่องที่ `D:\Scripts\FlightWatch` (ไม่ขึ้น repo เพราะมี access token)
